# Payload Structure of the PMS5003
## -The sensor gives a continous stream of 32 bytes every time it takes a reading 

1. The header (Bytes 0-3)
0&1: start characters, they just translate to BM in ASCII 
2&3: frame length, they will always be 0x00 and 0x1C which is equal to 28, (28 more bytes after this)

2. Mass Concentrations (Bytes 4 to 15), measured in µg/m^3. 
4&5: PM1.0 (standard) (1 byte has a max value of 255 which the readings go over)

6&7: PM2.5 
8&9: PM10 
10&11: PM1.0 (Atmospheric)
12&13: PM2.5 (Atmospheric)
14&15: PM10.0 (Atmospheric)

3. Raw Particle Counts (Bytes 16 to 27)
16&17: total count of particles larger than .3 microns 
18&19: total count of particles larger than .5 microns 
20&21: total count of partices larher than 1 micron 
22&23: total count of particles larger than 2.5 microns
24&25: total count of particles larger than 5 microns 
26&27: total count of particles larger than 10 microns 

4. Footer (Bytes 28 to 31)
28: firmware version  
29: Error code, but will be 0x00 if the sensor is healthy 
30&31: Cheecksum, the mathematical sum of all bytes from 0 to 29 will need to add to this. the code will add up the first 30 bytes and compare to this value before trusting the reading 




# PMS5003 Air Quality Sensor Reference

## 1. Hardware Intereface 
* **Communication** UART (Serial)
* **Baud Rate:** 9600 (8N1)
* **Power (VCC):** 5V required (for the internal fan)
* **Logic Level:** 3.3V TX/RX 



# Example Frame:

uint8_t frame[32] = {
  0x42, 0x4D, 0x00, 0x1C, // [0-3]   Header & Length 
  0x00, 0x12, 0x00, 0x1A, // [4-7]   PM1.0 & PM2.5 (Factory)
  0x00, 0x22, 0x00, 0x12, // [8-11]  PM10 (Factory) & PM1.0 (Env)
  0x00, 0x1A, 0x00, 0x22, // [12-15] PM2.5 (Env) & PM10 (Env)
  0x05, 0xC5, 0x01, 0xA4, // [16-19] Particles > 0.3um & > 0.5um
  0x00, 0x32, 0x00, 0x04, // [20-23] Particles > 1.0um & > 2.5um
  0x00, 0x00, 0x00, 0x00, // [24-27] Particles > 5.0um & > 10um
  0x97, 0x00, 0x03, 0x83  // [28-31] Version, Error, & Checksum
};
